# test_game

수업용 웹 게임 저장소입니다. 단일 HTML 파일로 만들어 GitHub Pages로 배포합니다.

## 플레이

https://weriousdf.github.io/test_game/

## 배포 설정

GitHub 저장소 → **Settings** → **Pages**

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

`main` 브랜치에 push하면 1~2분 뒤 자동으로 반영됩니다.

## 로컬에서 확인

`index.html`을 브라우저로 바로 열면 됩니다. 별도 서버가 필요 없습니다.
