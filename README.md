# 조선 호랑이 뜀박질 (Joseon Tiger Run)

크롬 공룡 게임을 조선시대 테마로 옮긴 HTML5 Canvas 2D 횡스크롤 무한 러너입니다.
외부 라이브러리·이미지·사운드 파일 없이 `index.html` 한 개로 동작합니다.

## 플레이

https://weriousdf.github.io/test_game/

- **PC**: `Space` 또는 `↑` 키로 점프
- **모바일**: 화면을 탭해서 점프

## 게임 규칙

- 달린 거리만큼 점수가 오르고, 100점 구간마다 속도가 빨라집니다 (5 → 최대 13).
- 장애물에 부딪히면 즉시 종료됩니다. 최고 점수는 브라우저에 저장됩니다.
- 지상 장애물(돌탑·장승)은 **뛰어넘고**, 낮게 나는 도깨비불·까마귀도 뛰어넘습니다.
- 높이 나는 도깨비불·까마귀는 **뛰지 말고 그대로 지나가야** 합니다. 300점부터 등장합니다.

## 구성

| 요소 | 내용 |
| --- | --- |
| 캔버스 | 800 x 300 논리 좌표, 화면 폭에 맞춰 축소 |
| 배경 | 원경 산 능선 2겹, 기와집 실루엣, 흙길 — 레이어별 시차 스크롤 |
| 플레이어 | 파란 아기 호랑이 — 이마의 임금 왕(王) 무늬, 긴 송곳니, 흰 발 |
| 장애물 | 돌탑, 장승, 도깨비불, 까마귀 |
| 저장 | `localStorage` 키 `joseon-tiger-run.hi` |
| 캐릭터 작업대 | `tiger-lab.html` — 게임과 분리해 호랑이 그림만 다듬는 도구 |

## 기술 노트

- **델타 타임 보정**: 매 프레임 60fps 기준으로 정규화하고 최대 3프레임분으로 제한합니다.
  탭을 전환했다 돌아와도 호랑이가 순간이동하거나 장애물이 건너뛰지 않습니다.
- **다중 점프 차단**: `isGrounded`가 `true`일 때만 점프 명령을 받습니다.
- **스크롤 차단**: `Space` / `↑` / `↓` 입력과 터치에 `preventDefault()`를 걸었습니다.
- **충돌 판정**: 사각 히트박스(AABB). 그림보다 히트박스를 작게 잡아 판정을 관대하게 했습니다.
- **효과음**: 파일 없이 WebAudio API로 생성합니다. 첫 입력 시 오디오를 초기화합니다.
- **난이도 안전장치**: 장애물 최소 간격(558px)이 최고 속도에서의 점프 이동 거리(473px)보다
  항상 넓어, 어떤 속도에서도 넘을 수 없는 배치가 나오지 않습니다.

## 캐릭터 수정

호랑이 모양을 바꿀 때는 `tiger-lab.html`을 먼저 엽니다. 게임과 **완전히 같은**
`drawTiger` 함수를 쓰면서, 확대 보기 · 달리기 사이클 · 배경 4색 대비를
한 화면에서 보여줍니다. 색상 10종과 비율 3종(머리 크기 · 몸통 폭 · 몸통 높이)을
실시간으로 조절할 수 있고, 화면 아래에 그대로 옮겨 붙일 코드가 출력됩니다.

값이 정해지면 `drawTiger` 함수와 색·비율 상수를 `index.html`에 옮기면 됩니다.
캐릭터 크기를 크게 바꿨다면 히트박스 `HB`도 같이 맞춰야 합니다.

## 로컬에서 확인

`index.html`을 브라우저로 바로 열면 됩니다. 별도 서버가 필요 없습니다.
